Multi-Source AGN Variability & Time-Series Analysis :
This repository contains the analysis of three distinct Active Galactic Nuclei (AGN) sources. The project focuses on characterizing variability through light curve simulation and periodogram analysis to understand the underlying physical processes of the central engine.

🚀 Project Overview :
The goal of this research is to apply advanced statistical methods to time-series data from specific astrophysical sources. By modeling the stochastic nature of these sources, we can constrain physical parameters such as the black hole mass or the size of the emission region.

Repository Structure :
The repository is organized by source to ensure reproducibility:

/plots: Generated Light Curves, Lomb-Scargle Periodograms, and Power Spectral Density (PSD) plots.
